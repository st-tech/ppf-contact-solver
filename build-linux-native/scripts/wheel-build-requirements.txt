# The build tools scripts/source-wheel.sh builds a wheel with, installed with
# --require-hashes into a throwaway environment and used with
# --no-build-isolation, so a build requirement cannot float to whatever the
# index serves that day. The versions satisfy the build-system requirements of
# every package scripts/platform.sh names. Each hash is the sha256 PyPI publishes
# for that file: Cython's two cp312 manylinux wheels and its pure-Python wheel,
# which pip takes for an interpreter neither platform wheel matches.
#
# To move a pin, take the version and every file hash from
# https://pypi.org/pypi/<name>/<version>/json together, and rebuild a wheel with
# scripts/source-wheel.sh before committing.
