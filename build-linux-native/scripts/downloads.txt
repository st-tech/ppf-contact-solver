# Single source of truth for every external download build-linux-native/
# performs, except the ffmpeg sources (see below). Format is plain KEY=VALUE,
# read by scripts/load-downloads.sh and probed by scripts/check-downloads.sh,
# which warmup.sh runs BEFORE it fetches anything. No URL belongs in any other
# file under build-linux-native/.
#
# A fetched file pairs URL_* with FILE_*, and carries SHA256_* when the thing
# the URL names is immutable. warmup.sh checks SHA256_* against the file on
# every run that provisions from it, whether this run downloaded the file or
# found a copy already in downloads/. That is what lets a host with no route to
# these hosts provision from a relayed downloads/ directory: an entry whose file
# is present and matches its hash is not probed and not fetched. To bump a tool,
# edit that entry's lines together, then run scripts/check-downloads.sh.
#
# THE FFMPEG SOURCES ARE NOT HERE. URL_FFMPEG_GIT, FFMPEG_TAG, URL_X264_GIT,
# X264_COMMIT and the zlib entry live in build-win-native/scripts/downloads.txt,
# which the Windows build and .github/workflows/scripts/make-slim-ffmpeg.sh
# already read. A copy here is how two platforms come to pin different ffmpeg
# revisions.

# rustup's installer for Unix hosts. warmup.sh fetches it only when the host has
# no cargo, and installs into build-linux-native/rust with CARGO_HOME and
# RUSTUP_HOME pointed there.
#
# No SHA256_ on purpose: sh.rustup.rs serves whatever rustup released most
# recently, so a pinned hash would go stale at rustup's next release. warmup.sh
# deletes a failed transfer rather than leaving it in downloads/, because the
# file is handed to sh and a truncated shell script runs the part that arrived.
URL_RUSTUP=https://sh.rustup.rs
FILE_RUSTUP=rustup-init.sh

# PER-ARCHITECTURE ENTRIES carry an _X86_64 or _AARCH64 suffix on every key.

# selected ones without the suffix (URL_PYTHON, FILE_PATCHELF). A host has no
# fallback to another architecture's file, which it could not run.

# SOURCE-BUILT WHEELS. A frontend package this architecture has no binary wheel
# for is built from its upstream source at a pinned commit by
# scripts/source-wheel.sh, and its source is never copied into this repository.
# scripts/platform.sh names which packages that is on each architecture. Every pin
# is a COMMIT, because a tag can be moved, and a submodule's commit is pinned as
# well and checked against the one its parent tree records. A repository pairs
# URL_*_GIT with *_COMMIT and has no FILE_*.
