# Single source of truth for every external download used by warmup.bat,
# build.bat, make-slim-ffmpeg.bat/.sh, and the Linux/Docker
# .github/workflows/scripts/make-slim-ffmpeg.sh. Format is plain KEY=VALUE so
# that both cmd (via scripts\load-downloads.bat) and bash (via
# `set -a; . scripts/downloads.txt; set +a`) can read it without a parser.
#
# Three kinds of entry. A fetched archive pairs URL_* with FILE_*, and with
# SHA256_* where its content is pinned; a cloned repository pairs URL_*_GIT
# with the tag or commit to check out, and has no FILE_*. An entry that differs
# by architecture carries a suffix, _X64 or _ARM64, on every one of its keys,
# and scripts\platform.bat copies this host's set onto the unsuffixed names;
# a missing suffix for this host is an error there, never a fall back to the
# other architecture's file. To bump a tool version edit that entry's lines
# together, then run scripts\check-downloads.bat to confirm the new pointer is
# reachable before the next warmup. No URL belongs in any other file.
#
# A VALUE MAY CARRY A `%` ESCAPE, and URL_PYTHON_ARM64 does (`%2B` for `+`).
# Every consumer reads these by NAME for that reason: a value passed through
# `call` is percent-expanded a second time, which rewrites the escape.

# THE TWO ARCHITECTURES SHIP DIFFERENT INTERPRETERS, and warmup.bat installs each
# its own way. x64 keeps the python.org embeddable distribution, plus the NuGet
# CPython that PyO3 links against because the embeddable one carries no

# The compiler and SDK the Windows binary is built with. Pinned here for the
# same reason every URL above is: without these, portable-msvc.py takes
# `max()` of whatever Microsoft currently publishes, so two builds of the same
# commit can use different compilers and the shipped executable is not
# reproducible from its source revision alone.
#
# These two values are what the unpinned selection resolved to on 2026-08-11,
# so pinning them changes nothing about the toolchain today and only fixes it
# in place. Note the maxima are NOT the newest versions the manifest lists
# (14.51 and 28000 at that date): those are previews, and portable-msvc.py
# excludes them unless --preview is passed.
#

# verify a full build on a Windows host before committing, exactly as the
# gist revision above requires.
