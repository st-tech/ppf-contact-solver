ZOZO's Contact Solver 🫶
========================

This site documents the Blender add-on and the JupyterLab Python API of
ZOZO's Contact Solver.

New to the add-on? Read the :doc:`Overview <blender_addon/index>`, then
:doc:`Getting Started <blender_addon/getting_started/index>`. To drive the
solver from a notebook instead, see the
:doc:`JupyterLab Python API <jupyterlab_api/index>`.
