## Questions, Bugs, and Requests

- **Bug reports and feature requests:**
  [open an issue on GitHub](https://github.com/st-tech/ppf-contact-solver/issues).
- **Usage questions:**
  [GitHub Discussions](https://github.com/st-tech/ppf-contact-solver/discussions)
  is the best place to ask.

Either route reaches the author and keeps the conversation searchable for
other users.

## Reporting a Bug

When you open an issue:

1. Attach a `.blend` file that reproduces the problem, if possible.
2. Remove copyrightable material from the scene, or replace it with openly
   licensed alternatives.
3. GitHub does not accept direct `.blend` uploads, so compress the file into
   a ZIP archive (for example, `scene.blend.zip`) before attaching it.

Issues are triaged in batches by a single part-time maintainer and labeled
`queued` (seen), `in-progress` (started), or `worked` (answered at least
once). A response can take a while.

## Email

To reach out privately, you can email the author at
[ryoichi.ando@zozo.com](mailto:ryoichi.ando@zozo.com).

Please do not send any copyrightable materials by email; anything of
that kind will never be read by the author and will be deleted upon
receipt.

## Code Patches and Reference Implementations

The project does not accept pull requests directly. Share code patches and
reference implementations in an Issue or a Discussion instead. This is the
route
[CONTRIBUTING.md](https://github.com/st-tech/ppf-contact-solver/blob/main/CONTRIBUTING.md)
describes. Submitting one there licenses it to the project and the community
under the [Apache License, Version 2.0](https://github.com/st-tech/ppf-contact-solver/blob/main/LICENSE)
on a royalty-free, unrestricted basis.

## Sharing Your Work

If you used this project in a public piece of work, whether a paper, a
production credit, or a personal project, the author would like to feature
it in the [project README](https://github.com/st-tech/ppf-contact-solver#-community-response).
Send a link to your article, project page, or website, not images or clips
themselves, since hosting them may run into licensing issues. The author
will consider adding it.
