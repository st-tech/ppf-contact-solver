# 🎛️ Parameters

The settings that control how the simulation behaves, grouped by where you
set them:

- [Material Parameters](material.md): per-group settings (density,
  stiffness, friction, contact, plasticity, velocity, locks, damping,
  intersection allowances), spatial material maps and material profiles.
- [Fabric Presets](fabric_presets.md): the bundled **Shell** and **Solid**
  materials and the fabric calibration report.
- [Scene Parameters](scene.md): scene-wide solver settings such as gravity,
  time step and frame count.
- [Dynamic Parameters](dynamic.md): the scene settings that you keyframe so
  they change during the solve.
- [Force Fields](force_fields.md): Blender force objects that push the
  simulated objects.
